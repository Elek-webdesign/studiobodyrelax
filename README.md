# Studio Body Relax

Sajt na jednoj stranici za Studio Body Relax, masaža na Zvezdari, Beograd.

## Objavljivanje na GitHub Pages

1. Napravite novi repozitorijum na GitHub-u i ubacite sve fajlove iz ovog foldera u njegov koren. `index.html` mora biti na vrhu.
2. Otvorite Settings, pa Pages. Source: **Deploy from a branch**, Branch: **main**, folder **/ (root)**, pa Save.
3. Posle minut-dva sajt radi na `https://<korisnik>.github.io/<repozitorijum>/`.

## Forma za upite

Forma šalje upit na mejl. Dok ne povežete servis za slanje, otvara mejl aplikaciju posetioca.
Kada napravite formu na [Formspree](https://formspree.io), upišite njen link u `FORM_ENDPOINT` na vrhu dela za formu u `script.js`.
